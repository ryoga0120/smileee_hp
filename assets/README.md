# smileee split assets

This folder contains separated PNG assets cropped from the smileee visual asset sheet.

Recommended usage:
- products/: product image cards for hero/product sections
- scenes/: lifestyle and research scene images
- value_cards/: ready-made value proposition cards
- value_icons/: icons for custom HTML cards
- icons/: small navigation/feature icons
- badges/: status badges such as development and monitor registration
- decorations/: blobs, waves, hearts, sparkles, footprints
- avatars/: team/user avatar cards
- sections/: larger convenience crops for quick mockups

Files are intentionally named in English/ASCII for easy use in HTML/CSS.
